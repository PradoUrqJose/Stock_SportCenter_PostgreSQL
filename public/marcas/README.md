# Logos de marcas del inventario

39 archivos SVG con `width="240"`, `height="120"` y `viewBox="0 0 240 120"`.

21 marcas cuentan con logo vectorial; los restantes son wordmarks tipográficos de respaldo porque no se encontró un SVG verificable. Los logos que compartiste se trazaron a paths vectoriales con sus colores cuando estaban presentes; `discovery.svg` conserva solo el tag. `reef-isotipo.svg` guarda por separado el símbolo de Reef.

El estado y la procedencia de cada archivo están en `fuentes.json`.
